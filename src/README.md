## 🚀 Quick Deploy to GitHub Pages

### Step 1: Create GitHub Repository
```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/hariom-chemicals.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under "Source", select `main` branch
4. Click **Save**
5. Your site will be live at: `https://YOUR-USERNAME.github.io/hariom-chemicals/`

### Step 3: Custom Domain (Optional)
1. In GitHub Settings → Pages, add custom domain: `www.hariomchemicals.com`
2. In your domain registrar, add CNAME record:
   ```
   Type: CNAME
   Host: www
   Value: YOUR-USERNAME.github.io
   ```
